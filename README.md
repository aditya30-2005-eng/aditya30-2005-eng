### SupportDesk <sub>· Helpdesk Ticketing System</sub>

<kbd>FEATURED · PYTHON &amp; DJANGO</kbd>

Customers raise support tickets, admins assign them to agents, agents update the status, and the customer gets an email at every important step.

- Role-based access for **customer, agent and admin** with Simple JWT, custom DRF permissions and queryset filtering
- **Event-driven emails:** a Django Signal queues a Celery task through Redis once the database commit is done
- Dashboard stats with Django ORM `annotate`, a React dashboard, and **58 API tests** running in GitHub Actions CI

### Real-Time Fraud Risk Scoring <sub>· Streaming Data Pipeline</sub>

<kbd>FEATURED · DATA ENGINEERING</kbd>

A real-time pipeline that ingests credit card transactions, validates them and scores each one for fraud risk.

- Streaming ingestion with **Structured Streaming** and validation on arrival
- Deduplication, fraud features, **velocity checks** and **location-hop detection**
- **Bronze → Silver → Gold** Delta Lake layers on Databricks
